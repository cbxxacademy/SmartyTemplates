# Web Development 1 - Rocket Elevators Digital Presence

## Project Overview

This module introduces fundamental web development concepts by creating a professional digital presence for Rocket Elevators using **HTML and CSS only**. You'll learn to modify existing code and create new pages with core web technologies.

## Key Concepts to Research

### HTML Fundamentals

- **Document Structure**: `DOCTYPE`, `<html>`, `<head>`, `<body>`
- **Common Tags**: `<div>`, `<section>`, `<a>`, `<p>`, `<h1-h6>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<form>`, `<input>`
- **Tag Structure**: Opening tags, closing tags, self-closing tags, nesting
- **Attributes**: `class`, `id`, `href`, `src`, `alt`, `title`
- **Semantic HTML**: Understanding meaningful element names

### CSS Fundamentals

- **CSS Integration**: Inline, internal, and external stylesheets
- **Selectors**: Classes (`.classname`), IDs (`#idname`), elements (`tagname`)
- **CSS Syntax**: Selector structure, properties, values
- **Common Properties**: Colors, fonts, spacing, layout, positioning
- **The Box Model**: Margin, border, padding, content

### Code Organization

- **Indentation and Formatting**: Clean, readable code structure
- **Comments**: Documenting your HTML and CSS
- **File Organization**: Managing multiple HTML pages and CSS files
